Connects to the FastAPI backend on the Pi. The page streams the solved angles with the speed and acceleration from Motion; the backend converts them to servo ticks and reads positions back.

Streaming

Hand-guide turns torque off so you can pose the arm by hand. Hold it first: it drops without torque. The stall check stops the arm when a joint stays well short of its goal without moving, which usually means something is in the way.

Calibration

In hand-guide mode, pose the arm like the sim's zero pose, then set the zero. Bend each joint by hand: if the green pose turns the opposite way, reverse that joint.

Playback speed1×

Playback moves to the start pose at Max speed from Motion, then follows the recording. With the timing kept, each joint gets the speed it needs (up to 150°/s); otherwise every joint uses Max speed and may lag. The whole path is collision-checked before it starts. When connected it runs on the arm itself, so it keeps going if you close this page. Stop or Esc ends it, and so does moving the target.
